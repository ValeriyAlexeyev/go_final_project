# Go Final Project — Планировщик задач

## Описание проекта

Go Final Project — это веб-приложение для управления личными задачами (TODO Planner), разработанное на языке Go в рамках итогового проекта Яндекс Практикума.

Приложение позволяет:

- создавать задачи;
- просматривать список задач;
- редактировать задачи;
- удалять задачи;
- отмечать задачи как выполненные;
- работать с повторяющимися задачами;
- хранить данные в базе SQLite;
- использовать готовый веб-интерфейс.

# Локальный запуск

## 1. Клонировать проект

```bash
git clone https://github.com/ValeriyAlexeyev/go_final_project.git
cd go_final_project
```

## 2. Установить зависимости

```bash
go mod download
```

## 3. Запустить приложение

```bash
go run .
```

или

```bash
go build -o scheduler
./scheduler
```

По умолчанию приложение запускается по адресу

```
http://localhost:7540
